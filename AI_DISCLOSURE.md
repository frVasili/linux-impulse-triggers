# AI disclosure

This project was developed through a human-directed investigation with
substantial assistance from OpenAI Codex.

Codex assisted with:

- inspecting current Linux, SDL, Wine/Proton, Steam, and controller paths;
- reading and comparing relevant upstream source code;
- designing and writing the SDL diagnostic programs;
- preparing the narrowly scoped udev installation and removal scripts;
- interpreting diagnostic logs and organizing the pipeline analysis; and
- drafting and editing the public documentation.

The human project owner:

- chose the objective and controlled the scope of the investigation;
- approved system changes and external publication;
- ran the game and interactive hardware tests;
- physically confirmed which of the four controller motors vibrated; and
- confirmed genuine independent trigger feedback during gameplay.

API return values alone were not treated as proof of physical behavior. Claims
marked as confirmed are based on source inspection and logs together with human
physical testing. Expected or unverified compatibility is labeled separately.

AI-generated code and analysis can contain mistakes. Users and contributors
should review the source, understand commands before running them, keep
permission rules narrowly scoped, and independently verify results on their own
hardware.
